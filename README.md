# JAGOAN GIZI — GitHub Pages

Versi ini sudah dipecah dari satu HTML besar menjadi `index.html` + folder `assets/`.
Tidak ada file yang melebihi batas upload browser GitHub 25 MiB.

## Upload ke GitHub

1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini dengan struktur folder tetap sama. Untuk hasil paling mudah, gunakan GitHub Desktop atau Git dari komputer.
3. Di repository, buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu **Save**.
6. Setelah deployment selesai, buka URL GitHub Pages repository Anda.

> Penting: jangan hanya upload `index.html`; folder `assets/` juga wajib ikut.
